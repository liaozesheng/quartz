
# VPS海外服务器选购完整指南
> 适用：美/欧/港海外VPS，重点解决线路踩坑、超售、带宽文字游戏、IP品质、测试流程。
> 核心原则：**不信商家宣传，看回程AS实测；优先月付测试，拒绝直接年付**。

## 一、先明确业务需求（选机第一步）
| 业务场景 | 核心关注点 |
|---|---|
| 国内用户访问服务器（建站、跳板） | **回程线路真理三色图，晚高峰稳定性**，优先精品回程 |
| 出海业务（海外用户访问，国内不上行） | 本地带宽、IP原生度，**不需要关心回国回程** |
| 账号环境、流媒体风控 | IP类型：住宅家宽IP / DC机房IP，区分BGP广播IP |
| 数据库、IO密集程序 | 磁盘IO，严防严重超售 |
| 爬虫、定时脚本任务 | 大流量带宽、流量配额、IP黑名单风险 |

> 重要区分：
> - **去程**：本地电脑访问服务器
> - **回程**：服务器数据包返回国内用户；国内访问海外服务器，**回程路由才是决定性因素**，真理三色图测的就是回程。

## 二、网络线路篇（最重要，AS对照表）
| 档次 | 电信 | 联通 | 移动 | 晚高峰表现 | 商家常见宣传话术 |
|---|---|---|---|---|---|
| ✅满配三网精品 | AS4809 CN2‑GIA | AS9929 CUII | AS58807 CMIN2 | 低抖动低丢包 | 三网精品、CN2+9929+CMIN2 |
| 🟡中档（欧洲常见） | AS4134 163普通 | AS9929 CUII | 移动借道9929 | 电信晚高峰拥堵，联通移动良好 | 三网9929（夸大宣传） |
| 🔴普通中国优化 | AS4134 163 | AS4837 169 | AS58453 CMI普通 | 20‑23点大概率丢包卡顿 | 中国优化、BGP优化、欧洲优化 |

### 高频坑点
1. **CN2‑GT**：国际段走CN2，回国切回AS4134，国内段依旧拥堵，伪GIA。
2. **移动借道联通9929**：不是原生CMIN2，跨运营商互联极端高峰期会拥塞。
3. AS8796这类机房本地AS：**只代表服务器本地网络，不能判断回国质量，要看跨洋之后的AS**。

### 真理三色图实操（必做）
服务器执行一键脚本，自动输出三网回程，截图即为真理三色图：
```bash
curl https://raw.githubusercontent.com/zhucaidan/mtr_trace/main/mtr_trace.sh|bash
```
> 说明：脚本为TCP回程，和ICMP‑MTR会有微小差异，但AS号判断可靠。
> ⚠️商家不给测试IP、不给三色图，谨慎购买，大概率隐瞒线路短板。

## 三、硬件与虚拟化选型
1. **虚拟化：优先KVM**
OpenVZ / LXC资源隔离弱，超售普遍，内核受限；仅学习实验场景可以使用。
2. 硬盘
- 首选 NVMe SSD（数据库高IO业务）
- SATA SSD 够用
- HDD仅适合备份，不要作为系统盘
3. CPU & 内存
低价机器普遍超售；上机执行`htop`，**steal time持续大于5‑10%，宿主机严重超售**。
> 不要盲目追求vCPU核心数，低价大多是超售虚拟核心。

## 四、带宽&流量，文字游戏重灾区
1. **端口速率 ≠ 保障带宽**
标注1Gbps端口，大多是**共享突发带宽**，空闲才能跑满，高峰期被邻居抢占。
2. 下单前确认三件事
1）单向计费 / 双向计费：正规VPS只扣**出站流量（服务器向外发送）**；双向计费实际流量直接减半。
2）流量超额策略：限速？停机？高额按量扣费？
3）“无限流量”：几乎全部附带FUP公平使用策略，不能长时间跑满带宽。
3. 计费模式
- 固定流量套餐：个人、建站首选
- 95峰值计费：商用大流量，个人不要碰

> 向商家提问模板：
> ①流量是单向还是双向？
> ②流量超额之后是限速还是扣费？
> ③带宽是保证带宽还是共享突发端口？

## 五、IP品质区分
1. **DC机房原生IP**
IP物理位置与机房一致；适合建站、跳板；风控系统识别为服务器机房IP。
> ipinfo.io查看，`type:hosting`

2. **住宅家宽IP**
Comcast / Proximus家庭宽带IP，流媒体、风控友好；
> ⚠️重点误区：**家宽IP不等于精品回程，家宽IP回国同样跑普通163公网**。
> ipinfo.io查看，`type:residential`

3. **BGP广播IP（伪原生）**
AS注册地在A国家，IP广播到B国家机房（例如AS8796，美国AS广播到比利时机房）。物理位置正确，但归属机构是海外公司，部分风控会识别异常。

> “原生IP”仅代表地理位置，**回程线路是独立采购的服务，二者互不绑定**。

## 六、计费续费避坑
1. **优先月付测试，严禁直接年付**。很多商家首月低价，续费大幅涨价，区分首单折扣价与正常续费价。
2. 退款政策：确认退款窗口；低价“灵车机”无售后，随时跑路，严禁跑正式业务。
3. 附加费用：额外IPv4、快照备份、DDoS防护是否额外收费。
4. SLA：玩具机器无所谓；商用业务关注SLA故障赔偿条款。

## 七、采购检查清单（下单前核对）
- [x] 索要测试IP，自行跑真理三色图，**不要只看商家提供的截图**
- [x] 确认虚拟化类型为KVM，避开OVZ/LXC
- [x] 确认流量计费模式：单向/双向，流量超额策略
- [x] 确认带宽：保障带宽 or 共享突发端口
- [x] 确认续费原价，区分首单优惠
- [ ] IP类型确认：机房IP / 家宽IP；是否BGP跨地域广播IP
- [ ] 月付上机，**晚上20‑23晚高峰复测丢包抖动；白天测试结果不代表晚高峰**

## 八、常见营销陷阱总结
1. ❌宣传“三网9929”：实际联通9929，电信163，移动借道9929
2. ❌宣传“CN2优化”：实际CN2‑GT，国内段切回163普通公网
3. ❌“家宽IP精品回国”：确认是BGP广播家宽IP叠加精品回程，**不是普通家庭宽带自带精品线路**
4. ❌只提供ping、下载测速截图，拒绝提供回程MTR三色图
5. ❌拿机房本地AS（AS8796等）当做回国线路卖点
6. ❌超低价大配置直接年付，灵车机跑路风险高
