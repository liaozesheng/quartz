# Vless+XTLS+回落+Trojan+回落+nginx监听80

```
1. 使用Vless协议+XTLS接收来自b.liaozesheng.top的数据，
		https://b.liaozesheng.top 传入数据
		Xray监听443端口，如果443端口的数据有vless协议的特征，能够通过id来进行识别，
		知道当前数据来自客户端，那么就会进行解析，拿到访问Google的请求，去访问Google
		
		Xray监听443端口，如果443端口传入的数据不能通过id进行解析，解密不通过，
		那么这可能就是GWT的探测攻击，我们使用回落原理，回落到本机的38388端口。
		
		Xray配置Trojan监听127.0.0.1:38388端口，443回落到38388端口的数据，由Trojan接收解析，
		Trojan通过密码38388对数据进行解密，如果解密通过则拿到Google请求，访问Google，
		如果解密不通过，则这个可能是GWT的探测攻击，所以，对于解密不通过的请求数据，Trojan协议
		配置回落到本机80端口，探测攻击数据包会被转到本机80端口。
		
		配置nginx，用来监听本机的80端口，如果有来访问本机80端口的请求，那么将会被转到nginx来
		进行处理，nginx通过反代，将数据流量导向一个正常的页面网址，用来欺骗GWT的探测攻击。
```



```
1.安装xray，
# bash -c "$(curl -L https://github.com/XTLS/Xray-install/raw/main/install-release.sh)" @ install -u root
编辑xray的配置文件，vim /usr/local/etc/xray/config.json
```

```
2.申请TLS证书，使用acme申请
#安装acme：
 curl https://get.acme.sh| sh
 #安装socat：
 apt install socat
 #添加软链接：
 ln -s  /root/.acme.sh/acme.sh /usr/local/bin/acme.sh
 #切换CA机构：
 acme.sh --set-default-ca --server letsencrypt
 #申请证书： 
 acme.sh  --issue -d 替换为你的域名  --standalone -k ec-256
 #安装证书： 
 acme.sh --installcert -d 替换为你的域名 --ecc  --key-file   /usr/local/etc/xray/server.key   --fullchain-file /usr/local/etc/xray/server.crt 

```
