# 交易目录说明

BTC 交易的判断卡与执行纪律记录。由 Hermes 的 `trade` profile 生成和维护。

## 子目录

| 目录 | 用途 |
|---|---|
| `判断卡` | 按交易日的行情判断，命名 `YYYY-MM-DD.md` |
| `知识卡` | 概念解释卡：一张卡讲透一个概念（入门向，先看这里） |
| `方法` | 方法论详解，把某一层的原理与算式讲透（附可复现的数据） |
| `复盘` | 按周期（每 10 笔或每月）的交易复盘 |

## 工具链

分析脚本在 `~/trading/scripts/`，日志在 `~/trading/journal/trades.csv`。

| 脚本 | 作用 |
|---|---|
| `daily_card.py` | 拉 OKX 真实行情，输出五层判断卡（首段为 VA 图；第5层含触发三条件判定、净RR、合格入场价上限） |
| `va_chart.py` | VA 图（成交量分布）：1D×300 / 4H×300 双窗口分桶 + POC + VA80 标记 + 现价线；`--price` / `--exclude-last-closed` 可复现历史快照 |
| `atr_study.py` | ATR 实证：TR 逐根明细、两种口径差异、ATR% 分布、k×ATR vs 固定百分比的被扫与假扫概率、周期换算 |
| `position_calc.py` | 仓位 / 止损 / 盈亏比 / 杠杆安全计算 |
| `journal_stats.py` | 日志统计：执行率、胜率、实际盈亏比、期望值、最大回撤 |
| `rr_study.py` | 第5层实证研究：触发规则检验、+2R 时间窗口扫描、RR 可行性扫描 |
| `find_pullback.py` | 检测「回调后站回」形态：严格口径扫描 + 逐根打印真实案例 |
| `big_candle.py` | 大阳线实证：短期代价、位置分布、站回富集、期望对照、逐根案例 |

## 四条硬规则

1. 止损距离 ≥ 1.5 × 日线 ATR；**止损不够远就放弃这笔，不要挪近止损**
2. 合约杠杆 × 止损距离 ≤ 50%（否则止损未触发就爆仓）
3. 用**最近的**阻力算 RR，≥ 2 才做；用最远目标算 RR 是自欺欺人
4. **90% 的时间正确答案是「不做 / 等」**

## 五层判断流程

```
第0层  三个否决：有仓位？刚亏过？找得到止损位？
第1层  方向（1D）：价格在 MA50/MA100 上方吗
第2层  位置（4H）：双层次区间百分位（中期 + 短期，必须一起看）
第3层  支撑阻力：成交量密集区 + 摆动高低点
第4层  波动率与止损：止损距离 ≥ 1.5 × 日线ATR（不够就放弃这笔）
第5层  触发与 RR：4H 收盘站回支撑 + 下一根不破前低；用最近的墙算净RR，≥2 才做
```

评分：方向(0-3) + 位置(0-3) + 止损明确(0-2) + 触发(0-2)，**≥ 7 才考虑**。
