# 第5层 · 触发与 RR（详解）

第5层回答两个**不同**的问题，两个都要过：

| 问题 | 由谁回答 | 不合格时做什么 |
|---|---|---|
| 现在可以动手了吗？ | **触发** | 等，写进观察位 |
| 这笔值得动手吗？ | **RR** | 等更好的价格，或放弃 |

**触发是必要不充分条件。** 触发成立只说明「回调可能结束了」，**不说明上方有空间**。这两件事没有任何关系，必须分开验。

> 本文所有示例数字的快照：**2026-09-13 21:35，现价 $76,672（约 ¥55.2万）**，
> 日线 ATR $2,094（2.73%），短期支撑 $76,001，合规止损区间 $3,141 ~ $6,282。
> 你在别的时点跑脚本会得到不同数字，但**结构和方法完全一样**。

---

## 一、触发

### 1.1 它到底解决什么问题

新手最常见的动作是「看到跌了就买」。这在专业术语里叫**接刀**：你不知道跌到哪算完。

触发规则做的事是把「**我觉得要涨**」换成「**图上出现了 X**」。X 必须是客观的、收盘后可以指着屏幕说「发生了 / 没发生」的东西。

### 1.2 本系统的两条触发条件

| # | 条件 | 为什么这样定 |
|---|---|---|
| ① | **4H 收盘**站回支撑位上方 | 盘中可以插针；收盘价才是市场共识 |
| ② | **下一根 4H 不破前低** | 单根站回可能只是反抽；第二根不破前低 = 买盘真的接住了 |

**为什么用 4H 而不是 15m / 1H 做触发**：因为止损距离会被周期压缩，而手续费按名义仓位收，
于是手续费占风险金额的比例会爆炸（同样 1.5×ATR 止损口径）：

| 周期 | 止损距离 | 手续费占风险金额 | 判定 |
|---|---|---|---|
| 15m | 0.24% | 42% | 🔴 每笔先亏掉四成风险 |
| 1H | 0.30% | 33% | 🔴 |
| **4H** | **1.30%** | **7.7%** | ✅ |
| 1D | 4.05% | 2.5% | ✅ 但机会太少 |

### 1.3 三种误用（都真实存在）

1. **提前进**：还没收盘就进。这等于没有触发条件，规则形同虚设。
2. **追突破**：价格从没跌破过支撑位，你买的不是「回调后站回」，是「追多」。
   对照 [[10-交易/判断卡/2026-09-13|2026-09-13 判断卡]]：最近 6 根 4H 最低 $76,500，
   **从未跌破** $76,001 → 触发 ① 判 ❌。此时站回不成立，因为它压根没被跌破过。
3. **把触发当买入信号**：触发成立，但上方 0.43% 就有一道 11% 成交量的墙 —— 照样不能做。

**记住顺序**：触发不是「信号」，是**过滤器**。它的作用是让你少做，不是让你做对。

### 1.4 触发的实证（真实数据）

样本：BTC-USDT 4H × **6,599 根已收盘**（3.0 年，2023-10 ~ 2026-09）。
支撑基准 = 前 12 根 4H（2 天）最低点；确认 = 站回后下一根不破前低。

| 检验项 | 实测 | 含义 |
|---|---|---|
| 「下一根不破前低」筛掉多少站回 | **19%**（34/176） | 五分之四的站回能通过，五分之一的站回是假动作 |
| 触发成立后止损 ≥1.5×ATR 的 | **46%**（66/142） | **触发后一半以上仍要放弃** |
| 触发 + 方向 + 止损合规全过 | 23 次 / 3 年 ≈ **1.6 个月 1 次** | 这才是「每周最多 1–3 笔」的真实来源 |

### 1.5 这份数据**不能**证明什么（必须说清楚）

- **不能**证明「等触发比不等更容易赚」。三层过滤后只剩 **23 笔**，50 笔以内谈胜率没有统计意义。
- 检验口径 ≠ 真实策略：上面用机械的「+2R」当目标，真实策略用的是「最近的墙」。
- 所以：**触发是纪律工具，不是收益来源。** 它买到的是「不接刀」，不是「更高的胜率」。

## 二、RR（盈亏比）

### 2.1 公式与单位 R

```
RR = (目标价 − 入场价) ÷ (入场价 − 止损价)
```

同时引入**单位 R**：`1R = 你愿意亏的钱 = 300 USDT × 5% = 15 USDT（约 ¥108）`。
之后所有账都用 R 记，和金额无关 —— 这样 300U 和 30,000U 是同一套结论。

### 2.2 RR = 2 的真实含义

不是「我要赚 2 倍」，而是「**允许我错 2 次、对 1 次，仍然不亏**」：

```
+2R × 1 次 = +2R
−1R × 2 次 = −2R
合计 = 0
```

最低胜率 = `1 ÷ (1 + 净RR)`：

| 净RR | 最低胜率（低于这个就是负期望） |
|---|---|
| 1.0 | 50.0% |
| 1.5 | 40.0% |
| **2.0** | **33.3%** |
| 2.5 | 28.6% |
| 3.0 | 25.0% |

期望值验算（单笔风险 15 USDT ≈ ¥108，净RR 固定 2.0）：

| 胜率 | 期望值/笔 |
|---|---|
| 30.0% | −0.100 R = −1.50 USDT |
| 33.3% | 0.000 R（临界） |
| **40.0%** | **+0.200 R = +3.00 USDT** |
| 50.0% | +0.500 R = +7.50 USDT |

### 2.3 三个变量里，只有入场价能动

| 变量 | 能不能为了凑 RR 而动 | 代价 |
|---|---|---|
| 止损价 | ❌ 不能挪近 | 2.24% 的止损三天内被扫概率约 54%（实测：2.0% 档 57.8%，3.0% 档 40.5%） |
| 目标价 | ❌ 不能挪远 | 到达概率同步下降，RR 好看但没意义 |
| **入场价** | ✅ **等出来的，零成本** | 唯一诚实的调节手段 |

### 2.4 毛RR 与 净RR（手续费怎么进公式）

手续费按**名义仓位**收，所以它同时抬高亏损、削减盈利：

```
净RR = (目标空间 − 入场价 × 往返费率) ÷ (止损距离 + 入场价 × 往返费率)
```

费率（OKX 全球区普通用户 LV1，往返 = 进场腿 + 出场腿；进场按挂单、止损按吃单）：

| 类型 | 往返费率 | 构成 |
|---|---|---|
| 合约永续 | **0.07%** | 挂单 0.02% + 吃单 0.05% |
| 现货 | **0.18%** | 挂单 0.08% + 吃单 0.10% |

**方案A（止损 $74,954，距离 2.24%）实测：**

| 目标（成交量密集区） | 空间 | 毛RR | 净RR(合约) | 净RR(现货) | 最低胜率 |
|---|---|---|---|---|---|
| $77,000（占比 11.0%） | +0.43% | 0.19 | 0.15 | 0.10 | 86.6% |
| $78,000（占比 15.3%） | +1.73% | 0.77 | 0.72 | 0.64 | 58.2% |
| $79,000（占比 11.6%） | +3.04% | 1.36 | 1.28 | 1.18 | 43.8% |
| $80,000（占比 9.4%） | +4.34% | 1.94 | 1.85 | 1.72 | 35.1% |

**手续费占风险金额 = 往返费率 ÷ 止损距离**（止损越近，占比越恐怖）：

| 止损距离 | 合约 0.07% | 现货 0.18% |
|---|---|---|
| 1.0% | 7.0% | 18.0% |
| 2.24%（方案A） | 3.1% | 8.0% |
| 5.0% | 1.4% | 3.6% |

### 2.5 「用最近的墙」—— 这条规则的数据依据

规则：目标必须取**现价上方第一个成交量密集区**，不能跳过它去用更远的。

我扫描了 2.9 年（6,299 根 4H）里每一根 K 线的「现价上方最近的密集区距离」：

| 指标 | 实测 |
|---|---|
| 最近的墙距离（中位） | **0.19 × 日线ATR**（P25 0.10×，P75 0.32×） |
| 做出 RR≥2 需要 | 目标空间 ≥ 2 × 合规止损(1.5×ATR) = **3.0 × ATR** |
| 距离 ≥3×ATR 的时间 | **0.0%** |
| 上方完全没有墙（已突破区间） | 12.3% |
| **合计可行时间** | **12.4%** |

**→ 87.6% 的时间，「合规止损 + 用最近的墙」两者在数学上不可能同时满足 RR≥2。**

原因很简单：密集区的墙是 $1,000 一档，而合规止损要 $3,141（1.5×ATR）。
**只要价格还在密集区内部，最近的墙永远在 $1,000 以内，RR 必然不合格。**

这就是「90% 的时间答案是不要做」的算术来源 —— 它不是经验，是可以逐根复算的数学。

**两个作弊陷阱**（用方案A的止损算）：

| 陷阱 | 手法 | 结果 |
|---|---|---|
| 止损设太近 | 止损挪到 1% | RR 能算到 4+，但三天内被扫概率约 73% |
| 用最远的墙 | 目标填 $82,285（中期上沿） | 毛RR **3.27**，看着「合格」—— 但那要连穿 4 道密集区 |

### 2.6 反解：合格入场价上限（最实用的一条公式）

给定止损 **S** 和目标 **T**，要做出 RR = k，入场价的上限是：

```
不含手续费：E = (T + k·S) ÷ (1 + k)
含手续费：  E = (T + k·S) ÷ [(1 + f)(1 + k)]        f = 往返费率
```

k = 2 时即 `E = (T + 2S) / (3(1+f))`。用方案A的止损 $74,954 反解：

| 目标 | 净RR=2 需入场 ≤（含手续费） | 距现价 $76,672 |
|---|---|---|
| $77,000 | **$75,583** | −1.42% |
| $78,000 | **$75,916** | −0.99% |
| $79,000 | **$76,249** | −0.55% |
| $80,000 | **$76,582** | −0.12% |
| $82,285 | **$77,343** | +0.88% |

**用法**：把「等更好的价格」从一个模糊感觉变成一个具体数字。
当天现价 $76,672 **高于上表中每一档的上限** → 现在入场，数学上就是不划算。

**兼容性条件（比 2.5 更硬的一条）**：把「止损距离 ≥ 1.5×ATR」和「RR ≥ 2」联立，可得目标位必须满足

```
T ≥ S + 4.5 × ATR          （S = 止损价）
```

代入今天的数字（S = 结构支撑 $76,001 下方 1.5×ATR = $72,860，ATR $2,094）：

```
T ≥ 72,860 + 4.5 × 2,094 = $82,283
```

而现价上方最远的那道墙（中期上沿）只有 **$82,285** —— 不含手续费刚差 $2，含手续费（0.07%）门槛升到 **$82,443**，**差 $158**。
若止损用更紧的 0.5×ATR 缓冲（$74,954），门槛升到 **$84,378**，上方一道都不够。

**换个看法（同一件事的入场价版本）**：取合规止损 $72,860，两个条件把入场价夹在一个区间里：

| 目标 | RR≥2 要求入场 ≤ | 止损≥1.5×ATR 要求入场 ≥ | 有解？ |
|---|---|---|---|
| $79,896（短期上沿） | $75,153 | $76,001 | ❌ 差 $848 |
| $80,000 | $75,187 | $76,001 | ❌ 差 $814 |
| $82,285（中期上沿） | $75,948 | $76,001 | ❌ 差 $53 |

**→ 结论：今天的结构下，「合规止损」和「RR≥2」无法同时成立 —— 而且不是「差一点价格」的问题，
是三条路都差一截。这就是「不做」的数学证明，不是感觉。**

要让它重新有解，只能等**结构变化**（ATR 缩小、止损位抬高），不是等价格挪动。

> 推导：设入场价 E、止损 S、目标 T。要求 (E−S) ≥ 1.5×ATR 且 (T−E) ≥ 2(E−S)。
> 由第二式得 E ≤ (T+2S)/3；代入第一式：(T+2S)/3 − S ≥ 1.5×ATR → T ≥ S + 4.5×ATR。

### 2.7 分批止盈的「有效 RR」（必须带前提）

| 方案 | 有效 RR | 前提 |
|---|---|---|
| 全部 1.5R 止盈 | 1.50 | 达到 1.5R |
| 50% @1.5R + 50% @3R | **2.25** | **第二段真的走到 3R** |
| 1R / 2R / 4R 各 1/3 | 2.35 | 第三段真的走到 4R |

⚠️ 上表是「最好情况」。如果第一段 1.5R 止盈后价格回落、第二段在保本被平掉：

```
0.5 × 1.5R + 0.5 × 0R = 0.75R
```

**不写前提的「有效RR」是误导。** 分批止盈降低的是心理压力，不是提高数学期望。

## 三、第5层的执行顺序（照这个顺序做，别跳）

```
1. 从第3层抄下「现价上方最近的成交量密集区」T1       ← 不跳档
2. 从第4层抄下合规止损区间 1.5~3 × 日线ATR
3. 定止损 S = 最近的摆动低点 − 0.5×ATR，且距离 ≥ 1.5×ATR
        ↳ 距离不够（<1.5×ATR）→ 这笔结束，不是挪近止损
4. 算 d = (E − S)/E、毛RR = (T1 − E)/d、净RR（扣往返费率）
        ↳ 净RR < 2 → 用 2.6 的反解公式算出「需要等到什么价」，写进观察位
5. 检查触发：4H 收盘站回支撑 + 下一根不破前低
        ↳ 未触发 → 等下一个 4H 收盘
6. 触发 ✅ + 止损合规 ✅ + RR≥2 ✅ → 才回到第0层做三个否决
        ↳ 第0层也过 → 用 position_calc.py 算仓位，挂限价单 + 同时挂止损
```

**三项缺任何一项，答案就是「不做」**，而且这是常态，不是失败。

## 四、自己复算（三条命令）

### 4.1 拉当天真实数据，看第5层全貌

```bash
python3 ~/trading/scripts/daily_card.py
```

输出里的第5层会给出：触发三条件逐条判定、止损合规性、毛RR / 净RR / 最低胜率、
以及「净RR=2 需要入场价 ≤ 多少」。

### 4.2 单笔验算（含杠杆与手续费检查）

```bash
python3 ~/trading/scripts/position_calc.py \
  --entry 76672 --stop 74954 --target 80000 --atr 2094 --lev 5 --fee 0.07
```

2026-09-13 用上面这组参数实测输出（原样粘贴）：

```
  账户资金          $      300.00   单笔风险 5.0% = $15.00
  入场 / 止损 / 目标  $76,672.00 / $74,954.00 / $80,000.00
  止损距离          $    1,718.00   = 2.24%
  ATR               $    2,094.00   止损 = 0.82 × ATR
--------------------------------------------------------------
  可买数量            0.00873108
  名义仓位          $      669.43   (账户的 2.23 倍)
  5x 杠杆需保证金  $      133.89   (账户的 44.6%)
--------------------------------------------------------------
  目标空间                  4.34%
  毛 RR                     1.94
  往返手续费        $       0.469   (占风险 3.1%)
  净 RR                     1.85   (税后)
  净 RR 对应最低胜率        35.1%
==============================================================
  ❌ 止损仅 0.82×ATR (<1) —— 必被随机波动扫掉，**放弃这笔**（不要挪近止损）
  ⚠️  止损 2.24% 偏近；手续费占风险 3.1%
  ✅ 杠杆×止损 = 11.2% ≤ 50% 安全
  ❌ 毛 RR 1.94 < 2 —— 不合格，等更好的入场价或放弃
  ✅ 手续费占风险 3.1%（单笔 $0.469）
==============================================================
  结论: ❌ 不合格 —— 不要做这笔
```

注意这里 `手续费占风险 3.1%` 正好等于 `0.07% ÷ 2.24%`，可以自己交叉验算。

（`--fee` 合约用 0.07，现货用 0.18。）


它会打印三项研究：触发的实证检验、`+2R` 的时间窗口扫描、RR 可行性扫描。

**时间维度的实测结论**（同一个 +2R 目标，不同观察窗口，单位 R）：

| 观察窗口 | 触发+方向 的期望值 |
|---|---|
| 1 天 | −0.103 |
| 3 天 | −0.224 |
| 7 天 | −0.138 |
| **15 天** | **+0.034** |
| 30 天 | +0.121 |

**→ RR=2 的仓位是 2 周级别的仓位。用 3 天的耐心去等 2R 的目标，几乎必然亏。**
这一条改变的不是入场规则，是你的**持仓预期**：入场前就要接受「可能要拿两三周」。

## 五、常见错误自查表

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 用盘中价判断触发 | 被插针骗 | 只看 4H 收盘 |
| 没跌破就买（追多） | 买在区间中部 | 触发①必须先成立 |
| 止损挪近去凑 RR | RR 好看，必被扫 | 止损不够远 = 不做这笔 |
| 用最远的墙算 RR | 假装中间的墙不存在 | 只用最近的密集区 |
| 忘算手续费 | RR 虚高（现货能差 0.2） | 用净RR，最低胜率同步上升 |
| 只看毛RR 不看最低胜率 | 不知道自己在要求多高的胜率 | 净RR 2.0 = 需要 33.3% |
| 用 3 天的耐心做 2R 的目标 | 大概率止损 | 2R 是 2 周级别 |
| 分批止盈当成提高期望 | 心理安慰 | 有效RR 必须写清前提 |
